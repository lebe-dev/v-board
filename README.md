# V-Board

Быстрая и гибкая клавиатура для Android.

[Зачем нужна ещё одна клавиатура?](docs/WHY.md).

## Возможности

- Поддержка голосового ввода
  - Встроенный движок Android, либо интеграция с [Говоруном](https://github.com/amidexe/govorun-lite)
- Поддержка LLM (OpenAI, Anthropic, OpenRouter и так далее)
- Slide to type для русского языка точнее чем в gboard
- Настраиваемые эмодзи (можно оставить только те, которые тебе нужны и добавить их в избранное)
- Словарь авто-замен
- Функция вычитки (удаление слов-паразитов, повторов)
- Настраиваемые кнопки на панелях клавиатуры
- Полноэкранный режим
- Поддерживаемые языки: русский, английский
- Поддержка тем
- Импорт\экспорт настроек
- Версия Android 14+
- Нет телеметрии по умолчанию, данные остаются на устройстве ([подробнее](docs/troubleshooting.md))
